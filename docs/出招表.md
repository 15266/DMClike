# 《DMClike》战斗Demo · 出招表

> 第三人称高速动作战斗 · 键鼠方案 · Unreal Engine 5.6 · 作者：陈嘉睿
> 按键映射基于项目输入配置 `IMC_Default` 及增强输入动作 `IA_*` 的实际绑定。

## 一、基础操作

| 操作 | 按键（键鼠） | 说明 |
| --- | --- | --- |
| 移动 | `W` `A` `S` `D`（或方向键） | 角色八方向移动 |
| 视角 | 鼠标移动 | 第三人称自由视角 |
| 跳跃 | `空格` | 支持二段跳 |
| 近战攻击 | 鼠标左键 | 普攻连段（轻 / 重击） |
| 远程攻击 / 瞄准 | 鼠标右键 | 远程攻击；按住进入瞄准 |
| 格挡 / 弹反 | `E` | 受击判定窗口内弹反 |
| 锁定目标 | 鼠标侧键（自定义键2）/ `左Shift` | 锁定最近敌人，并可切换目标 |
| 切换武器 | 鼠标滚轮 上 / 下 | 武器1 / 武器2 即时切换 |
| 调试面板 | `O` | 开发调试用，发布版本前移除 |

## 二、技能与连招

> 方向输入与攻击键组合可派生各招式。限定：通用 / 仅武器1 / 仅武器2

| 技能 | 操作方式 | 限定 | 备注 |
| --- | --- | --- | --- |
| 升龙 | `后` + 攻击 | 通用 | 向上挑斩 |
| 升龙浮空 | `后` + 攻击 + `C`（或鼠标侧键） | 通用 | 将目标击飞浮空，衔接追击 |
| 空中连击 | 空中按攻击 | 通用 | 滞空追击连段 |
| 处决 | 靠近敌人按 `F` | 通用 | 机制尚不完善 |
| 次元突进 | `前` + 攻击 | 仅武器1 | 位移突进斩 |
| 次元破空斩 | `Q` + 攻击 | 仅武器1 | 强力破空斩击 |
| 次元斩（时停） | 普攻出现闪光时按 `2`（`Y`+`B`） | 仅武器1 | 消耗 MP，范围时停大招（满屏交错刀光 + 短暂时停） |
| 飞剑发射 | 按住右键瞄准后按 `R` | 仅武器2 | 远程飞剑 |
| 飞剑突击 | 飞剑命中后 `前` + 攻击 | 仅武器2 | 追击突进 |

## 三、战斗资源与规则

- **HP / MP**：由角色与敌人蓝图变量管理，与战斗 HUD 实时联动。
- **MP 有限**：技能 / 必杀（如次元斩）释放消耗 MP，构成决策约束——不能无脑连放，需在输出与资源之间取舍。
- **敌方威胁**：重甲 Boss「极武道明真君」（敌人蓝图 `Raider`），手持多种武器拼杀并造成伤害，具备完整攻击、受击、霸体与死亡表现；同一套敌人系统支持多名敌人同场（可同时锁定最多 3 个目标）。

## 四、一局流程与胜负

- **获胜**：将 Boss「极武道明真君」的 HP 打空 → Boss 以溶解方式消失 → 屏幕弹出竖排「极武道明真君 击破」击败横幅。
- **失败**：玩家自身 HP 归零 → 弹出死亡画面。
- **重开**：点「再战不歇」重载关卡，从头再来。
- **推荐体验节奏**：开局与 Boss 近身拼刀 → 普攻连段建立爽感 → 升龙浮空 / 空中连击 → 次元斩（时停）打出峰值 → 溶解死亡与大破横幅收束。

## 五、调试面板（开发用）

> 运行时按 `O` 呼出（发布版本前移除）。

| 调试开关 | 作用 |
| --- | --- |
| AI 秒杀（完整死亡） | 一键让在场敌人直接死亡，播放完整溶解消失动画，快速检查死亡表现与横幅、尸体、箭的清理 |
| 角色死亡 | 直接触发玩家死亡，检查死亡画面与「再战不歇」重开逻辑 |
| AI 停止 / 恢复攻击 | 冻结敌人，单独测试玩家连段、位移与大招手感 |
| 魔能充满 | 将 MP / Drive 直接补满，立刻测试次元斩等耗魔大招及弹反、闪避 |
